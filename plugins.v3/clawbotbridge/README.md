# 微信ClawBot多账号（ClawBotBridge）

把多个微信号通过「微信 ClawBot」接入 MoviePilot 智能助手，替代内置的「微信 ClawBot」通知渠道。

## 和内置渠道的区别

| | 内置渠道 | 本插件 |
|---|---|---|
| 多个微信号 | 每个号建一个渠道 | 一个插件内任意多个 |
| 绑定用户 | 用户管理填 userid + 渠道白名单再填一次 | 扫码自动拿到 userid，配置里选一个 MoviePilot 用户即可 |
| 智能助手权限 | 渠道管理员名单决定 | 跟随绑定用户（普通用户无法执行管理员工具） |
| 回复方式 | 整段生成完一次性发送 | 按段落陆续发出多条 |
| 登录态 | Redis 缓存，3 天没轮询就过期 | 插件数据，长期保存 |
| 保存配置 | 重载时轮询线程收不回来会导致模块挂掉 | 只做差量调整，不重启运行中的账号 |

## 使用

1. 启用插件并保存。**先停用内置的「微信 ClawBot」通知渠道**，同一个微信不要两边同时登录。
2. 打开插件详情页，点「添加微信」，用要接入的微信扫码并在手机上确认。
3. 回到插件配置，给新账号选择对应的 MoviePilot 用户、要推送的通知类型，保存。
4. 在微信里给 ClawBot 发消息即可对话。

微信里可用的指令：

- `/new` 或「新对话」：清空上下文，开始新对话
- `/stop`：停止正在进行的任务

## 已知限制（iLink 协议实测）

- **无法逐字流式**：同一条消息的后续更新不会在客户端刷新，只能按段落发多条。
- **每条入站消息最多回复 10 条**：插件默认每轮最多 8 条气泡，超出部分合并进最后一条。
- **「正在输入」提示不显示**，插件改为在调用工具时发送进度消息（可关闭）。
- **主动推送依赖最近一次对话的会话凭证**：很久没和 ClawBot 说话时推送可能失败，给它发一句话即可恢复。
- 目前只处理文字和语音转写，图片、文件暂不支持。

## 实现说明

- `ilink.py`：iLink 协议客户端（对照腾讯官方 OpenClaw 微信插件 2.4.9）。
- `segmenter.py`：把智能助手的增量输出切成气泡，严格控制每轮额度。
- `agent_bridge.py`：通过宿主内部的 AgentSessionOwner 以绑定用户身份运行智能助手（与 Web AI 对话同一路径），依赖内部接口，MoviePilot 大版本升级时需复核。
